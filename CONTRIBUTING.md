## 🚀 How to Contribute

### 1. Report Issues & Suggestions
If you find a bug or have suggestions for improvement, please check the [Issues](https://github.com/ronnieshi79/AiRobot-Assistant/issues) first to see if there is already an ongoing discussion. If not, feel free to open a new Issue.

### 2. Code Contribution Flow
1. **Fork** this repository under your GitHub account or organization.
2. **Create a feature branch**: `git checkout -b feature/awesome-your-feature`
3. **Commit your optimization**: Ensure your changes follow the project's Kotlin coding standards and Vibe engineering architecture.
4. **Push to your fork**: `git push origin feature/awesome-your-feature`
5. Submit a **Pull Request** to the main repository.

### 3. Technical Standards & Agreements
- **Programming Language**: Kotlin (following official coding conventions)
- **Architecture Pattern**: Defined in [`docs/architecture.md`](./docs/architecture.md)
- **Collaboration Guidelines**: Following [`.agent/rules/code-guild.md`](./.agent/rules/code-guild.md) (Vibe Code conventions)
